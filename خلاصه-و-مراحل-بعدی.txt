📝 مرحله 1: تکمیل اطلاعات تماس
-------------------------------
فایل index.html رو باز کن و این خطوط رو ویرایش کن:

• خط 363: your.email@example.com → ایمیل واقعیت
• خط 368: yourusername → یوزرنیم تلگرام
• خط 373: yourprofile → یوزرنیم لینکدین  
• خط 378: yourusername → یوزرنیم گیت‌هاب

📤 مرحله 2: دپلوی سایت
------------------------

گزینه A: GitHub Pages (رایگان)
--------------------------------
1. یک repository در GitHub بساز
2. دستورات زیر رو اجرا کن:

   git remote add origin https://github.com/USERNAME/REPO.git
   git branch -M main
   git push -u origin main

3. Settings > Pages > Source: main branch
4. سایتت در https://USERNAME.github.io/REPO/ آماده می‌شه


گزینه B: Vercel (توصیه می‌شه - سریع‌تر)
-----------------------------------------
1. برو به vercel.com
2. "Import Git Repository"
3. اول کدت رو به GitHub push کن (مرحله بالا)
4. repository رو وصل کن
5. Deploy!
6. آدرس: https://PROJECT-NAME.vercel.app


گزینه C: Netlify
-----------------
1. netlify.com > "Add new site"
2. "Import an existing project"
3. GitHub repository رو متصل کن
4. Deploy!
